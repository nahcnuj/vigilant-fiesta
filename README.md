上から降ってくる数字と記号のブロックを、数式の形に並べてできた式の答えをスコアとして加算し続けるゲーム。

2013年制作のWindowsアプリケーション『[落ち物パズルゲーム](https://www.nahcnuj.work/works/2013/01_ochimono.html)』をリメイクした。

## Build

```bash
deno task build
# リポジトリ直下を配信（index.html / style.css / dist/main.js）
npx serve .
```
