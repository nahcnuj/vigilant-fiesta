# 落ち物パズルゲーム（Web版）要件・仕様書

## 1. 概要
昔Windows向けに開発された「落ち物パズルゲーム」をWebアプリケーションとしてリメイクする。
元のゲームは上から降ってくるブロック（数字や演算子）を配置し、数式を作って消していくパズルゲームである。

## 2. 動作環境・技術スタック
- **ターゲット**: 最新のWebブラウザ（Chrome, Firefox, Safari, Edgeなど）
- **技術スタック**: HTML, CSS, JavaScript (フロントエンドのみで完結する想定)
- **デザイン**: 現代的なWebデザイン（モダンなタイポグラフィ、アニメーション、洗練された配色）を取り入れ、UI/UXを向上させる。

## 3. ゲームルール・仕様

### 3.1. 画面構成
- **タイトル画面**: ゲームタイトルと「スタート」ボタン（または画面タップ/キー入力で開始）、簡単なルール説明を表示。
- **ゲーム画面**:
  - メインのパズルフィールド（横8列 × 縦10行）
  - 次のブロック（Next）表示
  - 現在のスコアとレベル表示
- **リザルト（ゲームオーバー）画面**: 最終スコアとランキング（トップ5）を表示し、タイトル画面へ戻る機能。

### 3.2. ブロックとフィールド
- **フィールドサイズ**: 横 8マス × 縦 10マス
- **ブロックの種類**:
  - **数字**: 0 〜 9
  - **演算子**: ＋ (足し算), − (引き算), × (掛け算), ÷ (割り算)
- **落下ブロック**: 2つのブロックが1セットになって上から落下してくる（ぷよぷよのような形式）。

### 3.3. 操作方法
キーボードによる操作を基本とする（スマートフォンなどのタッチ対応も今後検討可能）。
- **左キー (←)**: ブロックを左に移動
- **右キー (→)**: ブロックを右に移動
- **下キー (↓)**: ブロックを時計回りに90度回転
- **上キー (↑)**: ブロックを一番下まで瞬時に落下（ハードドロップ）
- **ESCキー**: ゲームを途中で終了（Web版ではポーズやタイトルへ戻る等のメニュー表示にしても良い）

### 3.4. ブロックの消滅とスコア計算
- 縦または横方向に「数字」「演算子」「数字」の順番で並ぶと数式として成立し、対象のブロックが消滅する。
  - 例: `1 + 3`
- 数式は右方向、または下方向に向かって判定される。
- **連続した数式**:
  - `1 + 2 × 3` のように演算子が連続する場合、`(1 + 2) + (2 × 3) = 9` のように個別の式として評価され、合算された値がスコアに加算される（元の仕様に基づく）。
- **特殊な計算結果**:
  - 引き算で結果が負になる場合、スコアから減算される。
    - 例：現在のスコアが30のときに `3 - 7` を作ると、`30 + (-4) = 26` となる。
  - 割り算で小数になる場合、小数第2位以下は切り捨てられてスコアに加算される。
- ブロックの消去処理は、フィールド全体の判定が終了した後に一斉に行われる。

### 3.5. レベルアップとゲームオーバー
- スコアが **250点** 増加するごとにレベルが1上がり、ブロックの基本落下スピードが上昇する。
- フィールドの一番上の段（一番高い位置）までブロックが積み上がり、新しいブロックを配置できなくなるとゲームオーバーとなる。

### 3.6. スコアランキング機能
- 過去のハイスコアトップ5を保存する。
- Web版では `localStorage` などを利用してブラウザ単位でスコアを保存する。

## 4. 今後の開発ステップ
1. **プロジェクトセットアップ**: HTML/CSS/JSファイルの作成と基本デザインの適用。
2. **描画エンジンの構築**: Canvas API または DOM（CSS Gridなど）を用いたフィールドとブロックの描画。
3. **ゲームループの実装**: ブロックの落下、移動、回転ロジックの実装。
4. **数式判定ロジックの実装**: 配置後のブロックから成立する数式を検出し、スコアを計算・加算する機能。
5. **画面遷移・状態遷移の実装**: タイトル → ゲーム中 → ゲームオーバー の流れを作る。
6. **デザイン・アニメーションのブラッシュアップ**: モダンでリッチなUI（エフェクト、サウンド、演出）の追加。
